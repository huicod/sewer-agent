# Backend conventions

- New video runs pin `video_selection_version=video-selection-v1`: bounded scene previews only prioritize detailed review; keep full primary coverage and original event PNGs. Scene calls share the existing video review budget, never count as defect/negative audit reviews, and checkpoint batches before final selection. Unpinned old runs retain old ordering; cached batches validate pinned context before checking mutable API settings. Error batch/call commits opt in to `save_step(..., allow_error_checkpoint=True)`; ordinary checkpoint status guards stay unchanged.

- Current code: Python 3.12, `backend/src/pipe_inspector`; tests: `backend/tests`.
- Configuration: `config.Settings`, server-owned environment prefixed `SEWER_`. Use SecretStr for credentials; never log settings dumps, authorization headers, or media bytes.
- FastAPI factories perform no model loading or network calls during import. `/health` means process liveness, not model/service readiness.
- Local delivery uses `scripts/app.py` for fixed loopback API/CPU/GPU processes; only the API receives the optional built `SEWER_WEB_DIST`. Preserve the `.venv/bin/python` launcher path (resolving its symlink bypasses the venv). Worker readiness follows Temporal startup; SIGTERM drains the worker. Stop/startup-failure cleanup never force-kills or deletes persistent data, and dependency readiness must include the application database connection/tables, not only the PG process.
- Models must be behind adapters. Domain contracts cannot import Ultralytics types. Existing five classes only; OTHER needs review, normal is a task conclusion.
- Temporal orchestrates; network, file, DB and GPU operations are Activities. No second custom retry scheduler or business state machine competing with Temporal.
- Open-detector supplementation is retired online (2026-09-12): no new open_scan run pins or plan admission. Keep historical workflow commands/schemas; production registers read-only retired handlers, never the archived OpenScanActivities executor.
- Test behavior before implementation. Unit tests use local fixtures; live model/API/service checks are explicit integration tests, never silently simulated as successes.
- Never equate an accepted offline evaluator with the online policy: verify the actual Workflow/Activity reviewer imports, persisted prompt/fusion pins and image views before claiming parity. SEDD external detection metrics only score XML-backed PL/BLOCK; absent FS/BX/AJ annotations are unscored, not negative ground truth.
- Dataset preparation does not authorize training. The merged-five selection excludes annotated non-target-only and mixed-target images rather than converting them to background; missing XML is not proof of normality. Preserve source/group manifests and freeze test membership; check source-by-split counts as well as global ratios (shared classes can hide a source missing from evaluation). Current version and limitations: `.trellis/tasks/09-16-merged-five-dataset/report.md`.
- New reviewed images default to guided_review (yolo-guided-review-v4 / guided-conservative-v1 / candidate-context-native-v1, validation-calibrated-v1 protection). Dispatch supported persisted mode/version tuples, never silently rewrite incompatible history; still reject model/API drift. Online and offline share agent/guided_fusion; review_pipeline parses nested evidence_strength for primary and optional-tool consumers. Keep advisory findings auditable and fusion predictions distinct; synthetic evaluation score 1.0 must never become VLM Finding confidence.
- Per-submission `inspection_mode` defaults to yolo_vlm for historical JSON and is part of task/turn idempotence. New image-only yolo_only runs freeze detector-only-v1, skip verify commands/VLM pins and use detector_only_rules confirmation provenance; never set negative_audit_complete or NORMAL from zero detections. Explicitly refuse unsupported video/tool combinations. Propagate new public literals through frontend validators, not only types; intentional skipped_by_mode evidence is not a missing/failed review.
- `evaluation.image_level` reads calibration caches only; retain the full sample_ids cohort and source annotation masks, including failures/empty GT. Deduplicate labels per image, keep IoU=.5 box references, bind second confirmations to exact proposals and report missing/error attempts. Rescoring is not a model improvement or a new acceptance definition.
- Image evidence exports read stored detect/verify checkpoints and current findings only. Keep original category/score, VLM advice and saved fusion changes separate; never recompute historical fusion or interpret a candidate score as confidence of its revised label. Missing evidence is unavailable, not normal. Historical tasks/review waits can expose evidence before a terminal report is available.
- Validation: `.venv/bin/python -m pytest backend/tests -q` and `.venv/bin/ruff check backend`.
- Keep distinct test basenames across unpackaged unit/integration directories so the full pytest suite collects. Paid video acceptance must require both explicit live gates and a configured output-token ceiling; count physical API attempts separately from selected review frames, stop processing timing at the human gate, and retain missing usage as unknown.
- Integration tests importing sibling test helpers use `backend.tests.*` paths and must collect standalone, not only beside unit tests that happen to extend sys.path. Disruptive service acceptance requires explicit dual gates, stopped managed app and an exclusive local runtime; preserve pre/post service identity, unchanged workflow run IDs and cross-process call evidence. Fixture model results demonstrate recovery, not accuracy or external exactly-once billing.
- Add only needed modules and dependencies. No routine file hashes, microservice scaffolding, new model training, or unrelated cleanup.
- Shared public contracts: `pipe_inspector.contracts`; use validated constructors/JSON parsing, not `model_copy(update=...)` for untrusted changes (Pydantic bypasses validation there).
- `TaskPlan.target_labels` is reporting focus, not a detector class filter. Runtime gating and transitions remain in the upcoming workflow.
- `ToolCall.idempotency_key` identifies a logical operation across attempts; record `attempt` separately. Database uniqueness/atomic commits must enforce this in the storage layer.
- Intake uses contracts/intake.py; initial submissions reference original image/video AssetRef IDs. The HTTP layer owns media upload and never accepts client filesystem paths.
- PostgresRepository uses short psycopg transactions and explicit init_storage.py DDL; no schema mutation during request/import. UUID request_id is unique and binds one immutable submission across retries.
- MediaStore preserves original bytes, uses Pillow for JPEG/PNG and bounded, file-only FFmpeg for video metadata/first-frame admission. Full video integrity/coverage belongs to later inspection.
- Video primary scan uses lossless BMP only for bounded temporary chunks; `decode_video_chunks` defaults and persisted evidence stay PNG. Preserve RGB pixels, original PTS, suffix/encoding agreement and chunk cleanup; do not pass scan-only format choices into evidence/VLM assets.
- Run storage integration explicitly with SEWER_RUN_STORAGE_TEST=1; each test uses and drops only its unique test-owned schema. Do not restart Temporal/PostgreSQL for intake tests.

- Shared DASHSCOPE_API_KEY is an explicit exception to the SEWER_ prefix: reuse only for explicitly configured Qwen roles on allowlisted official HTTPS hosts. Other providers need explicit role keys; never dump configuration secrets.
- OpenAICompatibleClient response_model validates locally; it does not transmit JSON Schema. Structured parsers must include their schema in the actual messages, with a captured-request test.
- Enhancement is one kind per run. Default auto_enhancement is false; current-turn opt-in admits a separate VLM tool selection after original detect/verify or from a linked original-image task's frozen evidence. Persist choice/skip before GPU execution, derive pins from admitted models, and never interpret downstream selection failure as failure of an already saved original review. Each explicit/auto follow-up uses a new operation child and request ID; identical request retries reuse that child. Atomic save_enhancement commits asset/call/checkpoint together. Auxiliary review preserves original boxes/classes/scores/coverage, sends conflicts/new anomalies to review, and must not turn a required-tool failure into a completable human gate. Retired detectors remain disabled.
- Restoration challengers live only in `vision/restoration_candidates.py` and the offline evaluator; do not promote them through online defaults without domain evidence. Same-input controls, original-coordinate mapping, aligned detail crops, and visible failures are required; detector retention is not truth, and ROI scores cannot be mixed with full-image accuracy.
- Geometry tools preserve the original image/frame raster and require an explicit box for segmentation. Count actual binary mask pixels; combine depth only from the same source/dimensions. Depth is per-image relative model units (preview white=near), not metres or cross-image-comparable distances; full-image mask fraction is not pipe blockage rate. Results require review and never rewrite detection/VLM verdicts. Original images accept an explicit ROI or a unique source finding for segmentation, and one operation package without enhancement/extra VLM mixing. Linked operations freeze original parent evidence and permit repeated operation children; conversational tool requests targeting a child resolve to its validated same-session/same-asset original root. Ordinary ask/report requests keep their selected child. Save geometry assets/call/checkpoint atomically; read cache before mutable environment/model checks. Required tool failure is partial, not a completable human gate; old runs without geometry add no commands.
- Selected video FRAME tools are the only derived-media admission exception: exact same-session persisted original evidence, `video-frame-tool-v1` source/observation/decision checkpoint, and an independent parent/frame/operation quota. Reuse ImageSupplementWorkflow, never primary detect/original verify; no whole-video/auto enhancement, arbitrary decoding or finding-ID geometry. Validate source at admission and atomic tool writes; all final findings, including new anomalies and configuration-change fallback, remain frame-local with exact locators. Never copy whole-video findings or coverage into a child.
- Saved comparison is a separate conversation action, not an inspection/supplement step. Bind two distinct same-session completed/partial tasks from original same-kind media; reference IDs come from selection or current text. Persist both snapshots and validated per-label/review-status counts under the turn lock, replay cache before live source reads, and never consume model calls or mutate source tasks. Reports describe saved findings, not physical alignment, repair success, or real defect appearance/disappearance.

- Independent conversations read `GET /api/sessions` summaries and complete `GET /api/sessions/{id}/turns` history; the intent-context default remains bounded. Session report exports retain each source task, root, mode, findings, tool calls and available evidence, and mark active snapshots non-final. Group by exact AssetRef, never infer duplicate-image identity or merge finding counts.
- Repeatable original-image operations use `sewer_image_operations` (task primary key, non-unique parent). Explicit `scripts/init_storage.py` adds it and idempotently copies historical `sewer_image_supplements` rows without deleting the old table. Stop the managed app before initialization/build/start. This is forward compatible; an old binary cannot represent newly admitted multiple children, so code rollback alone does not restore old admission semantics.

- Session metadata lives in additive sewer_sessions columns (custom_title, pinned, archived, metadata_updated_at), initialized explicitly. PATCH /api/sessions/{id} updates only supplied fields and returns the authoritative summary; title=null resets inferred naming, blank/oversized titles and non-boolean flags are invalid. Archive is organization metadata, not deletion/cancellation/admission gating, and list_sessions includes archived rows.
