# 图片检测模式与图像级离线评测

用户已批准继续原开发计划，并要求纯 YOLO 可选、保留框级评测，同时记录图像级评测。本轮实现这两个已对齐的入口，不继续调参。

## Acceptance

- 新图片任务可选择 `yolo_only` 或 `yolo_vlm`，默认保持现有 YOLO＋VLM。两者 YOLO 权重、输入尺寸和检测阈值一致。
- 模式经对话/直接任务 API 保存，参与幂等身份，重试和恢复不改变原选择。
- 纯 YOLO 不执行 VLM 复检；证据、界面和报告不声称已复检。无框显示“未检出五类缺陷”，不伪造阴性审计或正常结论。
- 本轮只支持图片的模式选择；视频仍用现有流程，服务端明确拒绝视频纯 YOLO 或不支持的纯 YOLO 工具组合，不静默升级。
- 离线 CLI 可从现有校准缓存重复计算图像级多标签 P/R/F1、每类、分来源和整图完全匹配率，保留同一批原框级统计；SEDD 仅评 PL/BLOCK。
- 不删除任何失败样本，错误/缺失二次确认不得算接受；无网络、无新依赖、无 API 开销。

## Non-goals

不改融合语义、检测器、数据划分、校准阈值；不重训、不跑新一轮付费实验、不修改 75% 验收定义、不推送远端、不启动部署服务。
