# T11 fixed incremental evaluation

## Goal

交付 T11 固定小集增量评估：主检测器、已接受的引导复检、条件开放候选的逐图依据、指标与待人工审查清单。

## Requirements

- 固定复用 confidence/paired 的 36 张及 regression 的 12 张 Sewer2403 图片与缓存复检；不使用 SEDD，不宣称独立测试集。
- 小量既有真实视频帧另列；无人工标注时不计算视频准确率，也不代表完整视频覆盖。
- 开放检测沿用 T10 触发、默认参数、只增不删/待人工确认策略；不修改生产默认、提示词、模型或原标注。
- 原标注匹配指标与实际误报判断分离，新增候选不当作已确认缺陷。输出实际阶段图片、逐条来源、JSON/CSV 审核清单及运行成本/失败/恢复记录。
- 优先复用已有 VLM 响应，新增本地开放模型调用；无新付费 API、训练、平台或数据大规模提取。

## Acceptance Criteria

- [x] 固定输入身份/元数据与参数可检查，检查点复用、配置变更拒绝；失败明确记录，不当正常。文件本体不做完整性校验，禁止同版本原位覆盖。
- [x] 自动测试覆盖阶段指标、无标注视频、只增不删融合、失败/恢复与图库内容。
- [x] 真实固定集运行并保存各阶段图像、机器可读结果及人工待审清单。
- [x] 明确工程验收与有效性验收边界；人工真值未补齐不得虚报整体精度提升。
