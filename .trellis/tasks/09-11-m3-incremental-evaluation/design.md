# T11 设计

扩展 evaluation 包，离线重放已有观测与复核，复用 guided-confidence-v2 及生产 merge_open_candidates。后者仅构造待审队列；本轮不会把实验引导复核切成生产默认。

每个固定输入保存 sample_id、来源/路径、尺寸、原标注（视频未知为 null）、原观测、复核、视频定位。运行保存完整输入与配置快照，逐样本原子检查点；重跑只补未记录样本，错误保留。使用版本与内容比较，不引入哈希系统。

这里比较的是结构化快照，不证明磁盘文件内容一致；同版本文件须保持不变，更换原图/模型须新身份或路径。CLI 另以入库的 fixed-set.json 锚定 48+8 样本，审核 CSV 通过 finding ID 与源定位/图库链接回溯。

共享 T10 单帧触发判断，零框质量合格或复核怀疑漏检才扫描；视频证据以帧探针衡量，不冒充事件调度/全片评估。开放框复用生产只增不删去重，保留 OTHER 待审但不混入五类指标。

报告三层：primary、guided、combined（guided + 开放待审五类）。combined 仅候选覆盖上限，不是自动确认准确率；原标注未匹配框称“未匹配”，不能直接断言真实误报。附逐样本原标注匹配增失、待审数量、覆盖、失败、缓存/新增调用与耗时。

复用现有图库生成原图/检测/复核/融合/原标注，增加开放层与待审联合层；未标注视频明确标注未知。人工审查 CSV 保留未审状态，不自行补真值。
