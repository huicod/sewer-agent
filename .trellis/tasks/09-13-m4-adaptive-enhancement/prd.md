# T12-C 可选主动增强与低照度恢复

2026-09-13 用户批准上一轮结论并要求开发。T12-B 基线 `d7afd3ac`，本任务 jj `skwvwmyl`；Trellis 是唯一任务状态，沿既有增强闭环扩展。

## 验收

- 普通图片任务不增加增强/API 调用；明确指定增强仍按 T12-B 执行。用户可通过对话允许 Agent 按需增强，也可保持关闭；权限只作用于该次任务，不能从历史消息偷偷继承。
- 原图检测与原 VLM 后，独立工具选择器根据原图、质量线索和冻结检测证据提出最多一种增强，允许放弃。后端验证退化类型、理由、原图 ROI、已部署模型与预算；不能由低置信度或亮度阈值直接决定执行。
- 增强选择、跳过原因、执行与辅助复核可追溯、可恢复，并显示在现有对照面板。原图/原框/原标签/原分数保留，新增与冲突待审；失败不伪造成功。
- 增加真实预训练低照度恢复，本机 GPU 输出派生图；优先比较 DarkIR 与 HVI-CIDNet 可用权重，保存少量 Sewer2403 逐图对照。模型选择以缺陷可辨识性为目标，不宣称公共榜单或质量分数等于管网检测增益。
- 自动分支在原始单帧任务支持；视频和已完成任务的自动补证先明确拒绝，既有显式关联增强保持可用。

## 非目标

不改变已验收原 VLM Prompt/融合；不重启开放检测器；不训练模型；不加入固定多工具串行链、第二调度器、通用插件平台或图像哈希。其余去雾/去模糊/超分候选继续分阶段比较，不凭模型年份直接替换。
