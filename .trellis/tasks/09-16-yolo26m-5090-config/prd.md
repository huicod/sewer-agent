# YOLO26m / RTX 5090 训练配置与调试余量

用户授权修改训练配置为YOLO26m；当前实测RTX5090 32607MiB，Torch2.8.0+cu128支持sm120。
这是既有训练脚本的限定配置调整；不正式训练、不改变数据划分、不恢复线上服务、不推送。

## 交付与验收

- 保存明确的YOLO26m通用预训练配置，指向merged_five_v1；输入960、固定batch8起测、AMP开、workers4、CPU线程4、禁多尺度/compile/RAM缓存。
- 最大100epoch、patience30，优化器MuSGD显式指定，与旧auto长训练实际选择一致；保留现有常规增强，不做超参搜索。
- 训练进程PyTorch allocator预算16GiB，启动检查显存余量；解释不是GPU硬件分区或GPU算力限额，不承诺任意并发绝无OOM。
- 对已有train_detect.py新增显式profile入口及dry-run，保留旧CLI；profile配置不得被旧默认值静默覆盖。
- 短程真实训练/验证显存预检，不作正式训练结果；使用train内固定小子集，保存资源证据，测试集不参与。
- 并行现有检测器单图推理探针，检查调试余量；不调用LLM/VLM或跑增强/分割全工具集。
- 有针对性的测试、一次独立审查、参数/显存/使用边界报告和本地版本交接。正式训练待用户确认。
