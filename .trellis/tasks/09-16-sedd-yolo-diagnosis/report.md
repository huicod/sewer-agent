# SEDD 纯 YOLO 漏检诊断

2026-09-16；代码基线`b1173b1b`（`v0.1.0-prototype`）；本次只增加离线评测/记录，不改产品代码、阈值、权重或VLM策略，不训练、不启动应用/Temporal、不推送。**本轮LLM/VLM调用均为0**。

## 结论

两张上传图片的零输出已复现：模型原生推理与在线适配器一致，均无分数达到0.25的框，不是适配器吞框。完整可靠SEDD子集确有严重低召回，但不是所有图片都无法检测。相同类别口径的源域对照表现明显更好，支持跨域性能退化；本次不能进一步证明光照、管材、纹理、标注尺度或训练分布哪一项是主导因果。

单纯降阈值、修改类别编号或把输入放大，不足以解决已观察到的问题。源域模型本来就不是全类高精度模型：历史验证集PL召回58.5%、FS召回43.2%，FS mAP50仅35.9%；旧12/48图源域例子不能代表独立泛化能力。历史数据来自[训练报告](../../../yolov26/docs/sewer2403_5class_experiment_report.md)，不是本轮重跑原验证集。

## 实际配置与两张上传图

- 权重：`yolov26/experiments/sewer2403_5class_yolo26s_img960_e100/weights/best.pt`。
- 真实names：`0=PL, 1=BX, 2=FS, 3=BLOCK, 4=AJ`，与训练五类映射一致。
- 在线适配器默认`imgsz=960, conf=0.25`；原图直接进入检测器，没有先增强、裁剪或VLM修改。
- 上传文件先按大小定位候选，再逐字节确认原图来源（没有建立hash系统）。两份均960×542，XML内部filename、尺寸和边界有效。

| 上传任务 | 完全相同的SEDD文件 | 原始标注 | 960下最高候选分数 | conf≥0.25输出 |
|---|---|---|---:|---:|
| `fd8042d1-f45c-4bce-9ce8-139af96baaf8` | `00002.jpg` | 5个crack＋1个deposit | 0.113922 | 0 |
| `667bbdfd-4482-4b57-81fa-b269e912b52c` | `00016.jpg` | 1个crack | 0.004879 | 0 |

第二张的原标注不是FS；这不等于图中不存在腐蚀，只是没有FS真值可用于计算腐蚀召回。960下未返回任何score≥0.001的FS候选。

两图分别用640/960/1280尺寸对照，所有尺寸在conf≥0.25均为0框。第一张降到0.05出现3个PL候选，但与原标注IoU≥0.5的命中仍为0（局部小框不能算命中原标注的大框）；第二张降至0.001仍无标注命中。不能把“出现框”直接称为有效召回。

## 数据与公平口径

SEDD原包有7563张JPG、2562份XML；924份XML内部filename与文件stem冲突，另5001张无XML。本轮保守排除它们，使用**全部1638张无该冲突且尺寸/边界有效的配对图片**，不是随意选困难图。

- `crack → PL`：1234框；`deposit → BLOCK`：518框；共1752个可评分目标。
- `root → OTHER`，不映射为BLOCK或FS；522张root-only不是正常图片。另5份空XML也不能据此认定真实正常。
- SEDD没有FS/BX/AJ标注，因此这三类预测保留在原始JSON，但**不计入SEDD的TP/FP/FN**，summary明确标记unscored。不能提供五类外部精度。
- Sewer2403固定seed=20260916，PL/BX/FS/BLOCK/AJ/OTHER各40张，共240张、228个五类框；按现有文件名分组规则去重。五类映射为原PL/BX/FS/AJ保留，CJ/JG/ZW合并BLOCK。
- 原训练划分丢失，240图可能与训练重叠，且GT分层抽样改变类别比例；只作推理健康对照，不能替代原验证/独立测试。SEDD也缺真实管段/视频分组信息。

本轮同一GPU/权重/960尺寸、单图推理，先在conf=0.001保存预测，再离线过滤固定阈值。主指标为**同类别、IoU≥0.5、置信度降序的一对一目标级匹配**；不是mAP。FP仅表示未匹配原标注，不等于人工确认的误报。

## 主结果（conf=0.25）

| 数据/评分范围 | TP / FP / FN | Precision | Recall |
|---|---:|---:|---:|
| SEDD 1638图，PL＋BLOCK | 131 / 65 / 1621 | 66.84% | 7.48% |
| Sewer2403 240图，同PL＋BLOCK口径 | 83 / 28 / 13 | 74.77% | 86.46% |
| Sewer2403 240图，全部五类 | 197 / 41 / 31 | 82.77% | 86.40% |
| SEDD：PL | 105 / 59 / 1129 | 64.02% | 8.51% |
| SEDD：BLOCK | 26 / 6 / 492 | 81.25% | 5.02% |

SEDD共1420/1638图没有任何五类输出；其中1111张有PL/BLOCK标注的图片中，908张没有任何输出。另有FS23/AJ11/BX1共35个预测未评分，未误计为FP。

把匹配IoU放宽到0.1（仅诊断，不作为主指标），SEDD召回也只有10.22%，不能仅用严格框定位口径解释主要低召回。

## 阈值诊断（仅SEDD PL/BLOCK，未修改在线配置）

| conf | TP / FP / FN | Precision | Recall |
|---|---:|---:|---:|
| 0.25 | 131 / 65 / 1621 | 66.84% | 7.48% |
| 0.10 | 192 / 158 / 1560 | 54.86% | 10.96% |
| 0.05 | 225 / 302 / 1527 | 42.69% | 12.84% |
| 0.01 | 328 / 1078 / 1424 | 23.33% | 18.72% |
| 0.001 | 495 / 4831 / 1257 | 9.29% | 28.25% |

低阈值确能补出部分候选，但带来大量未匹配/重复框，且召回仍低。作为VLM参考候选的阈值可以另行校准，但本轮没有证明调整后系统整体效果更好，也未选择新默认值。

## 另一个已确认的在线集成差异

当前`ImageInspectionWorkflow`每图执行`detect_image → verify_image`，不是只在低置信度时调用VLM；检测失败等异常路径除外。当前在线`ImageReviewer/image-review-v2`发送**原图＋YOLO类别/分数/坐标JSON**，不画框、不发候选局部图；零框时JSON列表为空，VLM做全图审计。

用户认可的旧离线实验是`GuidedImageReviewer/yolo-guided-review-v2`，含原图＋最多8个上下文局部图，融合为`guided-confidence-v2`。当前在线仍是`image-recall-v1`，未接入上述离线方案。代码证据：`workflow/activities.py:20-30,227-239`、`agent/image_review.py:155-184`、`agent/guided_review.py:98-178`、`evaluation/guided.py:11`。此前“原VLM策略不变”的交接未清楚说明实验与在线版本不同，需要纠正；这项差异不导致YOLO初检零框。本次仅记录，后续需单独对齐并验证集成，不偷偷修改已发布初版。
