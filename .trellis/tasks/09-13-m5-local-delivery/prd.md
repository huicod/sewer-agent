# T16 本机一体化运行入口与交付说明

## Goal

在已配置的GPU服务器上统一构建、启动、状态、停止和重启Agent原型，提供可操作的本机网页与简短运行手册。基线25e49c62；不把T15未完项或规范缺项写成已交付。

## Requirements

- 复用现有FastAPI、CPU/API worker、串行GPU worker及原生PG/Temporal，不新增框架/依赖/公网服务。
- 单一本机网页入口含API；停止应用保留数据库、媒体与Temporal任务，重启后仍能查询既有记录。
- 重复启动不重复进程；拒绝占用端口/不匹配PID；启动失败清理本次子进程，不能误停他人服务。
- 状态区分进程存活、启动已就绪及持久依赖就绪；缺配置/前端构建时给出安全可执行错误，不泄露密钥。
- 停止优先正常退出；超时明确失败且保留进程记录，不自动强杀，不自动终止任务或删业务数据。
- 手册含配置、构建、启动/停止/恢复、日志/数据目录、SSH访问与当前限制；不覆盖.env，不推送，不做新精度或付费模型试验。

## Acceptance Criteria

- [x] 控制脚本相关失败回归通过；网页/API同源、worker就绪与退出有可执行验证。
- [x] 本机启动/重复启动/状态/停止/重启实测成功，保存记录与访问截图；不调用真实推理/API。
- [x] 文档、总体进度、Trellis/jj及一次独立审查完成，证据见report.md。

## Notes

- 不提供新服务器安装器、自动开机服务、自动监督重启或互联网鉴权部署；已有任务恢复仍由Temporal负责。
