# T15-E 业务工作流跨服务中断恢复验收

## Goal

补齐 T15 当前业务路径的真实服务重启验收：图片人工等待保留，视频从已提交块续跑，不重复已保存的计算或落库。

## Requirements

- 使用现有 ImageInspectionWorkflow、VideoInspectionWorkflow、HumanReviewGate 和 PG，不以 M0 探针替代。
- 隔离 schema、队列、合成媒体和模型替身；不调用付费 API，不改检测/VLM/融合策略。
- 显式重启开关和本机专用集群检查；应用停止、无其他工作流时才允许中断。
- 只杀本测试 worker；失败亦尝试恢复依赖，清理只限自有测试资源。

## Acceptance Criteria

- [x] 图片快照/原框/工具记录跨重启保留，测试专用审核可完成且幂等。
- [x] 视频首块提交后中断，恢复全帧覆盖，已提交帧不重算、无重复记录。
- [x] 保存前后状态、workflow/run ID、调用计数、覆盖和恢复耗时，明确替身边界。
- [x] 默认无重启，相关测试、回归、Ruff、一次独立审查通过。
- [x] 日常应用恢复可用，Trellis/jj/总体计划保存进度。

## Notes

既有总体计划已获实施授权，本轮限定 T15-E；规范检索等用户输入，图片策略和视频性能不在本轮范围。
