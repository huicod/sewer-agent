## 2. 评分规则与四组预测

每张图片的标注框、预测框分别去重成类别集合 G、P，并与该数据源可评类别取交集。
不使用 IoU，不计同一类别的实例数量，不要求预测框位置与标注一致。
本次仅投影已有框的类别，不额外从 VLM 自由文本、共存建议或无框异常中提取新类别。

```text
TP = 各图 |G ∩ P| 之和
FP = 各图 |P - G| 之和
FN = 各图 |G - P| 之和
Precision = TP / (TP + FP)
Recall = TP / (TP + FN)
F1 = 2TP / (2TP + FP + FN)
整图类别完全正确率 = G 与 P 完全相同的图片数 / 图片总数
```

Precision/Recall/F1 均为 micro 汇总；不是“猜中任意一类即整图正确”，也不是含大量
真负例的标签位 accuracy。以下 TP/FP/FN 单位是“图片—类别”，不能与框级计数直接相减。

| 组别 | 逐图预测取法 |
|---|---|
| A：纯 YOLO 基线 | 第一轮 `observation.detection.detections` |
| B：当前保守融合 | 第一轮 `conservative_predictions`；本批与 A 的框集合完全一致 |
| C：首轮新增框离线投影 | 第一轮 `predictions`；原 YOLO 框加当时通过实验门的新增框，不是全部 VLM 建议 |
| D：新增框独立第二次请求确认 | B 加第一轮 `experimental_additions` 中，第二轮对应 `sample_id::index` 的 `accepted=true` 且无 `review_error` 的框 |

C/D 都是离线实验，不是线上默认策略，也不是纯 VLM 检测。
第二轮为同一 VLM 的新请求，不是不同模型提供的独立证据。
第一轮 1 张请求失败仍按 YOLO 回退纳入全部 60 张；第二轮 2 个失败候选不升级为新增框，
不删除这些图片。没有通过只统计成功样本抬高指标。

同一批预测的原框级结果（同类、IoU ≥ 0.5、一对一匹配）：

| 方案 | 框级 TP / FP / FN | 框级 Precision | 框级 Recall | 框级 F1 |
|---|---:|---:|---:|---:|
| A/B | 69 / 38 / 39 | 64.49% | 63.89% | 64.19% |
| C | 70 / 60 / 38 | 53.85% | 64.81% | 58.82% |
| D | 69 / 52 / 39 | 57.02% | 63.89% | 60.26% |

纯 YOLO 的 F1 从框级 64.19% 变成图像级 90.77%，来自定位、数量、重复框不再受罚等
评分条件变化。C 的图像级召回高于 A，但 Precision/F1 低于 A；D 也未超越 A。
因此更换评分单位仍不能证明 VLM 融合总体优于纯 YOLO。

## 6. 样例与标注局限

[sample-0018](../../../var/evaluations/2026-09-18-vlm-calibration/live-60-conf025/gallery/sample-0018/index.html)
对应 `sedd__01213`。标注、YOLO 和该样本融合结果的类别集合都是 `{PL, BLOCK}`，
所以图像级完全正确；但 index=5 的底部区域仍被 YOLO 标为 PL（0.26014），VLM 提出
BLOCK 意见后仅保留待审。图像级得分不会揭示这个局部改类问题，不能据此认为它已解决。

分类评价可消除定位和同类数量不一致的影响，但若整个 FS 类别被漏标，报出 FS 仍会计为 FP。
本报告 FP 指“与现有参考标注不一致”，不等于每项都已人工证明是假缺陷；也不能反过来
认定所有额外预测都是真缺陷。漏标/错标修正需要人工确认，另存标注版本，供所有方案公平复算。
