# T10 conditional open-candidate detection

## Goal

实现已批准路线图 T10：YOLOE 首个开放候选适配器、条件式图片/视频调用、可恢复执行及人工确认。不改变既有主检测/VLM 策略。

## Requirements

- 原五类结果不可被覆盖，新候选（含五类与 OTHER）均需人工确认。
- 配置后仅在显式 open_scan、质量足够的负结果、VLM 疑似漏报及视频周期审计帧上调用；有预算，不逐帧双跑。
- 固定配置和选择结果到新运行，旧运行不新增 Activity。调用可追踪、失败不输出虚假正常，成功检查点复用。
- GPU 串行释放切换；请求时禁止自动安装/下载。不训练、不改标签、不追加付费实验、不推送。

## Acceptance Criteria

- [x] 可替换适配器输出原图坐标与受控缺陷词表。
- [x] 触发/跳过、去重不覆盖、预算/失败、旧运行兼容及人工审核有测试。
- [x] 图片和已有视频证据帧可持久调用；显式请求未配置时拒绝执行。
- [x] 真实本地模型冒烟通过，不据此宣称精度提高。
- [x] 回归测试、一次集成审查及三项修正、Trellis 报告/进度及 jj 检查点。
