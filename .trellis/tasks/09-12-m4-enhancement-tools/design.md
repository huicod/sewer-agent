# T12 图像增强：按已批准主方案展开

本阶段分两个可验收切片：T12-A 先提供三个真实预训练工具、统一输入输出/坐标映射、保守质量门控和小样本原图对照；T12-B 将这些已验证工具接入对话、Temporal、报告与辅助复检。本任务交付 T12-A，不把离线可运行冒充在线已接通，也不将 T12 整体标完成。

输入为原 CCTV 图片或已保存的视频证据帧；每次仅运行一种 dehaze / deblur / super_resolution。超分只处理明确 ROI，记录原图尺寸、实际裁剪框和输出尺寸；输出框映射回原图后才能交下游。原图不可覆盖；增强产物附父资产、模型版本、处理方式、前后质量摘要，不是新的缺陷真值。

复用现有 QualitySummary/analyze_quality，不修改当前检测/VLM质量判定。新门控默认只建议而不自动执行：低对比不是雾的确诊，低清晰度不是可恢复细节的证明；过暗、过曝不自动套这三种模型。没有域内效果证据前保持自动关闭；显式工具调用可执行已配置模型。模型/包缺失、输出维度或像素非法、ROI越界、预算过大等必须失败，不用插值/锐化冒充模型成功。

模型通过独立适配器加载可信本地权重，首次配置时获取官方代码/权重，推理期间不下载。GPU串行按需装载/卸载，限制输入/输出像素；保留现有Torch/CUDA，无训练、无YOLOE分支、无VLM提示词/融合更改。

验证分开记录：单元/契约与故障测试证明工程边界；三种本地真实模型加少量固定Sewer2403图片证明可运行并提供原图/增强图对照。质量分数改善不算准确率提升；本轮不调用付费VLM、不做新检测器实验。
