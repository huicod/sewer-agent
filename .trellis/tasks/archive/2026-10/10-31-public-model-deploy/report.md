# Public release verification

- The operator requested public visibility for the existing Hugging Face model repository. The model release is [suwewa/sewer-agent-models at e542e8d7](https://huggingface.co/suwewa/sewer-agent-models/tree/e542e8d77a94496c431d829c1fa541c363c4baf6). The 15 runtime assets are byte-identical to the previous release. Stored weights total about 1.07 GiB with their required configs. New model-card metadata and upstream notices preserve attribution and the detector's embedded AGPL-3.0 license.
- The official Hub endpoint returned public visibility using anonymous access to the fixed revision. All seven remote SHA-256 values matched the approved release checksums. The four published explanatory documents were independently compared byte-for-byte against the local generated versions. The GitHub code repository remains private.
- 56 focused tests passed, including first use and repeated deployment, external providers, missing keys, failed fetch, same-size weight corruption and older model directory metadata. Scoped Ruff and diff checks passed. Actual legacy release files were reused offline and their generated metadata upgraded in a temporary copy.
- The production command defaults to all services, including the GPU worker. The test runner selects the web/API and CPU services together with PostgreSQL/Temporal. Native GPU inference for all seven unchanged weights has [separate evidence](../10-31-docker-deployment/report.md). No paid provider calls were made.
- [GitHub Docker acceptance on dev/agent-v1, 59966713](https://github.com/huicod/sewer-agent/actions/runs/41172667988) passed all steps. From an empty directory the same deployment command downloaded 15 real assets and verified seven weight hashes. With one synthetic shared key it started the web app and CPU services, uploaded a PNG, and read back its original bytes and session after recreating containers. The second run reused all models and the saved configuration.
- On AutoDL, an initial anonymous request for the 897,897,416-byte SAM2 checkpoint stopped at 890,665,097 bytes and the installer rejected it. After network recovery the HF CDN served the missing 7,232,319-byte suffix with HTTP 206 and those bytes matched the original.
- After network recovery, AutoDL ran the shipped anonymous fetch command from an empty directory and obtained all 1,146,385,002 required bytes. SHA-256 of each of the 15 files matched the original. Repeating the command with an unreachable download proxy validated the complete cache without further traffic. The fresh download, verification and repeat took 264 seconds. Evidence: `var/runtime/docker-validation/public-fetch-smoke.json`.
