# T15-D 真实视频资源与 API 用量验收

## Goal

补齐 T15 的真实视频资源证据：运行当前视频工作流，记录全帧覆盖、各阶段耗时、GPU 峰值及 Qwen 实际请求/token 用量。

## Requirements

- 沿用现有五类检测器、视频事件聚合和条件式 VLM 复检，不修改产品策略、默认预算、模型或 Prompt。
- 使用已授权 CCTV：完整 22.401953 秒短视频；如需第二样本，固定另一视频的 30 秒连续片段并标明原始时间偏移。单次真实验收最多 8 个物理 API 请求。
- 真正执行 PostgreSQL/Temporal、FFmpeg、本地 GPU 和 Qwen；仅验收入口增加测量。默认测试不付费。
- 人工等待是验收观察点，不自动代替人工批准；处理耗时截止该观察点，不包含等待及清理。
- 隔离本次 schema、队列、资产和输出；不重启共享服务、不覆盖旧实验、不给长视频精度或普适成本背书。

## Acceptance Criteria

- [x] 可重复 opt-in 入口与离线测量/预算测试通过。
- [x] 至少一个完整真实视频：完整可解码帧数、事件/证据/选中复检帧、各阶段时间和显存落盘。
- [x] 安全逐请求 usage 与调用上限证据落盘，缺失 usage 不当作零；费用估算与真实账单分开。
- [x] 主 Agent 核对原始 JSON 与代表性证据图，一次独立审查、测试及 Trellis/jj 检查点完成。
