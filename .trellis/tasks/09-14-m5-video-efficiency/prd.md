# 视频全覆盖扫描提速与收尾阶段说明

## Goal

在不改变像素、全帧覆盖、检测/VLM策略和恢复语义的前提下，消除视频初查临时 PNG 编解码开销；同时明确剩余四个交付收尾阶段。

## Requirements

- 临时初查帧与持久证据分离；证据仍为 PNG，旧资产和报告兼容。
- 只改已有视频解码/初查入口，不训练模型、不增加依赖、不做抽帧降采样。
- 使用同一真实视频与现有权重前后对照，核对逐帧检测/质量/事件与处理时间；不重复付费 VLM。
- 保留按块清理、原 PTS、失败和断点续跑，不使用无限缓存。

## Acceptance Criteria

- [x] 测试验证临时无损帧像素等价、默认 PNG 不变、完整扫描/续跑/失败清理仍通过。
- [x] 同视频逐帧结果对照和前后时间落盘，无不能解释的行为变化。
- [x] 相关测试、一次独立审查通过，进度和有限收尾计划保存到 Trellis/总体计划。

## Notes

本轮完成扫描路径性能切片，不宣称有效片段筛选、长视频全项验收或首版交付完成。
