## Deliverable

Small deterministic evaluator + explicitly opt-in resumable CLI, not a platform. Existing ImageReviewer/OpenAICompatibleClient, decide_image, review_required and UltralyticsDetector must be reused. Fixed inference conf=.25, imgsz960; use current model/Prompt/policy without tuning. Report this operating point, not mAP from unlike val threshold .001.

Input JSON manifest with documented schema: top-level `dataset_name`, `split_provenance` (nonempty factual note; never inferred), `samples` list. Each sample: `sample_id`, `group_id`, `image_path` (local explicit path), `ground_truth` list of five-class label + original-pixel bbox, `width`, `height`. Require unique IDs and one sample per group for this pilot, valid boxes/dimensions, max sample count passed by caller (default48). No image/GT filenames/labels sent as VLM instruction; only original image and detector observation go to ImageReviewer. Manifest itself is supplied by user/root after GT-only sampling; evaluator never selects based on predictions.

Metrics (pure tests with hand-computed boxes): class-aware greedy descending-score IoU>=.5 one-to-one matching; TP/FP/FN, precision/recall/F1, per-class and micro, FP/image; image-level five-label-set exact match. Compare (a) raw detector boxes, (b) retained five-class queue (all non-rejected findings with localized evidence), (c) auto-confirmed findings only. Report pending/abstain counts separately: precision gains from deferral do not by themselves mean accuracy improved. Non-localized VLM suggestions are not valid detector boxes; count separately and include five-label-set suggestions only with explicit metric distinction. No true-normal accuracy or mAP claim. Additional/revised VLM suggestions stay pending per actual policy; no silent autoaccept.

API failures remain in denominators: call decide_image with review_error, retain whatever production policy retains, count failures; do not drop hard cases. Persist raw baseline observation, safe review/error and decision per image. `summarize` can recompute metrics offline without API; output paired deltas and number of improved/worsened/unchanged image label sets, not a blanket improvement claim. A small standard-library paired bootstrap CI for micro-F1 delta is optional only if simple; not required for a48-image exploratory pilot.

CLI: `--manifest`, `--output` directory, `--max-samples` (default48), `--live` explicit flag required for any detector/API inference; dry/summary mode only reads saved output. Reuse cached per-image observations and successful/error review records; first fixed manifest + nonsecret config equality must be checked on resume, no hashes. No semantic retries or automatic re-calls for saved failures; at most one review API call per uncached eligible image, sequential. Missing VLM config must fail before GPU/any call. Tooling cannot guarantee no duplicate billing if crash occurs after provider success but before local save; don't add a scheduler. CLI output safe counts/metrics only, never Settings dumps, secrets or raw provider errors. Input path/manifest is explicit operator-owned local interface, not public HTTP.
