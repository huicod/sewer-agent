# T07 视频初查核心＋复核效果先导评估

用户已批准继续总体计划，同时要求验证复核是否提高准确率。视频开发与小规模图片对照评估分开验收，不预先承诺收益。

- 视频核心读取离线 CCTV：所有可解码帧、真实 PTS、有限大小图片批次；检测器仍用现有 DetectorAdapter。
- 跨块保存聚合状态、确定性事件标识，短暂单帧异常不丢弃，选择少量高质量/时间分散证据。事件只表示连续可见片段，不保证物理缺陷身份。
- 本阶段提供可测试核心和显式本地 CLI，输出候选/覆盖/证据索引，不把零候选写成正常。网页视频执行、Temporal 长任务恢复和取消留在 T08，不偷偷改成同步 HTTP 长任务。
- 同一留出图片集对照原检测器和当前条件式 VLM 策略；阈值/样本在看结果前固定，报告 TP/FP/FN、P/R/F1、待审比例与失败数。五类空标注不等于管道正常。
- 不训练、不调参、不增视觉模型、第二编排器或通用评估平台；不做媒体/模型哈希。API 仅调用用户已配置的 Qwen，小试验有显式次数上限。

验收：真实 FFmpeg/VFR/跨块重放及短暂异常测试；小视频实际 GPU 冒烟；固定样本真实复核前后指标或明确的数据/费用阻碍；相关回归与独立审查，Trellis/jj 交接。
