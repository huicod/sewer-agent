- Windows 自带 PowerShell 可启动；支持 WSL/Ubuntu 安装提示、管理员/重启/首次用户创建后重复同命令续装。
- 官方 Docker Engine、Compose、NVIDIA Container Toolkit 来源；利用 Windows 显卡驱动。安装到 WSL 文件系统，可从私有 GitHub 下载 ZIP 开始，不要求先有 Windows Git/Python/Docker。
