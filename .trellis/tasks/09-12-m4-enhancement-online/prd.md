# T12-B durable conversational image enhancement

## Goal

在现有图片 Agent 中接通显式增强、持久检查点、原图对照和辅助 VLM 复核；原检测/复核流程及历史证据保持兼容。

## Requirements

- 新上传图片检查：原图检测和原图 VLM 先完成，显式选择一种增强，再做原图/增强图辅助复核；未请求增强的任务命令序列不变。
- 已完成/部分完成的原图片任务可通过对话追加一次增强补证；复用既有单次 supplement 准入/冻结证据，不另开无上限工具任务，不修改父任务。
- 对话只提供工具种类及可选原始像素 ROI，模型/路径/预算由服务端决定。超分缺 ROI、混合未部署工具、视频增强明确拒绝/澄清，不静默少做。
- GPU 串行；版本和参数冻结；增强资产、成功调用和检查点原子提交；重放使用已存结果。明确失败不伪装完成，不因画质分数增加而放宽正常条件。
- 辅助复核使用原图和增强图，不替代原图 VLM；保留原发现类别/框/分数，分歧及新增疑似异常进入人工审核。自动增强仍关闭。
- 页面和 JSON/HTML 报告展示派生证据、来源、工具阶段、质量及辅助复核说明；Trellis/jj 保存工程进度。

## Acceptance Criteria

- [x] 契约/对话/配置/顺序/错误/融合保留边界的红绿测试。
- [x] 真实 PostgreSQL 原子落盘、并发重试；Temporal worker 更换后继续且已存增强不重做。
- [x] 前端对照及网络校验测试、构建；后端完整回归、Ruff、一次独立审查。
- [x] 小型本地 GPU/受控 API 接通证据；记录实际调用和未验证边界，更新交接/总体计划。
