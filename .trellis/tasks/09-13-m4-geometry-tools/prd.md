## 范围与验收

- 原始 CCTV 图片/原始帧 + 显式原图坐标框 → 真实分割掩膜、叠加图、像素统计；不增删或改类既有发现。
- 同原图 → 真实单目相对深度数组和可视化，标明远近方向；无标定不输出毫米、真实距离、体积或堵塞率。
- 分割/深度可独立执行；量化只组合同源同尺寸结果，输出图像平面占比和掩膜内相对值摘要，不跨图比较。
- 复用资产契约和 MediaStore，原始数组/可视化分开，派生文件不覆盖原图；增强图不可量测。
- 一个分割模型和一个深度模型、本地权重、按需加载/卸载、单 GPU 串行，无隐式下载。缺框、坏尺寸/输出、空掩膜、非有限/常数深度明确失败。
- 固定 4–6 张 Sewer2403 原图，保存来自既有 YOLO 或显式指定的框、实际掩膜/深度、JSON、时间/显存与图册。框不当作掩膜真值，不重跑 VLM。
- 自动测试覆盖来源/坐标/单位/失败/卸载，真实 GPU 另验。任务、报告、路线图、jj 保存，无推送。
