# T13-A：分割与相对深度工具交接

2026-09-13；jj `kwvrmtsk`；基线 `1bb1b42f`。T13-A 本地工具与六图实测完成；T13-B 在线接入待续，不代表整套 T13 已完成。

## 交付边界

- SAM 2.1 Hiera Large 接收原图和一个坐标框，生成真实二值掩膜与叠加图；不接收类别字母、不自行判缺陷。Depth Anything V2 Small 独立读取同一原图，生成 float32 相对深度数组与预览。两个可替换适配器使用本地官方 safetensors、FP32，逐次加载/卸载。
- 面积统计来自掩膜像素，不是 YOLO 框面积。`image_plane_fraction` 分母是整张图；相对深度是单图模型单位，白近黑远；两者均不是毫米尺寸、真实管径、体积或堵塞率。掩膜可越出提示框，不暗中裁剪美化结果；所有量化结果要求复核。
- 本轮仅完成可复用本地工具/契约与离线验证入口，未开放对话工具准入，未接 Temporal/数据库原子检查点或前端面板。原检测、已验收 VLM/融合、增强策略不变，开放补检保持停用。

清单 [samples.json](samples.json) 在推理前固定。六张原图来自既有 `2026-09-11-guided/paired/gallery`；0003/0007/0015/0022/0025 分别使用缓存 YOLO 最高分 PL/BX/FS/AJ/BLOCK 框。0033 没有五类候选，使用开发 Agent 在推理前显式指定的管口区域，仅示范形状工具，不将它变成新缺陷。均未重跑 YOLO 或 VLM。

无掩膜或深度真值，Sewer2403 也可能与训练数据重叠；本实验不计算分割 IoU、深度准确率或缺陷 P/R。视觉合理性与工具执行成功分开解释。

实测 [六图图册](../../../var/evaluations/2026-09-13-geometry-tools/verified/index.html) 与 [完整 JSON](../../../var/evaluations/2026-09-13-geometry-tools/verified/results.json) 已写入 `var/evaluations/2026-09-13-geometry-tools/verified`，原实验未覆盖。每组保存：

六张图全部完成分割、深度与统计，0 执行失败。下列观察来自逐张查看实际叠加图和深度预览，不是人工真值评测；分割质量估计不作为缺陷置信度。

深度在管道图中主要给出近壁亮、管道远处暗的平滑趋势；0003 的细裂缝没有可靠深度细节，0025 的蓝色画面遮挡块还在深度中形成方块印迹。**当前只能作为可选远近参考，不能声称已提高缺陷准确率、测得裂缝深度或恢复真实三维。**

12 次工具调用累计 16.13s，含各次加载、推理、卸载和资产写入；不含首次下载、进程启动及图册副本整理。单次最高 CUDA allocated：分割约 1,357 MiB，深度约 354 MiB（同进程序列，含已有分配），均在 RTX 3080 Ti 12 GiB 上完成。本轮另有两个模型各一次启动烟测，无 API 调用。首次权重获取是主要等待：HF snapshot 路径停滞后改用官方固定版本直连；以后运行只读本地权重。
