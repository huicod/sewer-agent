# 人工测试示例：6 张图

这组图片用于手动体验当前工作台。6 张源图覆盖五类标注线索，以及暗光、模糊、反光、文字遮挡等困难情况；用同一批图继续测试模式选择、人工复核、增强、几何分析和报告，无需增加样本数量。

**只想先试三张：按 01 → 05 → 06 的顺序。** 完整覆盖再补 02、03、04。每个目录都有 `image.jpg` 和可直接复制的 `prompt.md`；先只做各文件里的「首轮」，后续步骤按需选做。

## 在页面里怎么操作

1. 若浏览器在自己电脑上运行，先把这个 `example` 文件夹下载到本机；服务器路径不能直接填进本机文件选择器。也可以下载同目录的 `manual-test-pack.zip` 并解压。
2. 在右侧「检查助手」中选择对应的 `image.jpg`，使用「对话附件（可选）」上传。新附件用于新建检查，不要在「更换任务或对比结果」折叠区另选已有任务。
3. 「检查模式」选择 **YOLO＋VLM 复检**，复制该样本的首轮 prompt 到「对话内容」，发送并观察任务状态。助手回复“已启动”不等于检查已完成。
4. 中间详情里点击「查看媒体证据」，再展开「检查依据」，核对原始框、复检意见和最终发现。若进入「等待人工复核」，按自己对证据的真实判断处理，不能照着目录名称一律确认；无法判断时可保留待复核。
5. 记下任务 ID。检查助手默认关联中间正在查看的任务；输入草稿后会锁定当时的目标，避免编辑途中误切任务。若之后切换了查看任务并希望草稿改为讨论新目标，点击「讨论当前查看的任务」。需要手动指定任务或比较两个结果时，展开「更换任务或对比结果」。后续追问或工具操作不要附带新附件。

新建检查弹窗也可上传这些图片；提交入队后，还需在任务详情里点击「开始检查」。通过此入口选择「纯 YOLO（不复检）」可测试本地检测流程。

## 复用图片的两个对照测试

### 同图两种模式

用 01 的同一张图片和同一条首轮 prompt，分别新建 **YOLO＋VLM 复检**、**纯 YOLO（不复检）** 两个任务，保存各自的任务 ID。模式必须在页面下拉框里切换；已有任务的模式不会被后续 prompt 改写。

观察两种结果是否正确显示自己的检查模式和证据来源。纯 YOLO 无框时应表述为“未检出五类缺陷（未复检）”，不能把它理解为人工审核后的正常结论。也不要求两种模式的缺陷数量必然不同。

若正在查看的是纯 YOLO 根图片任务，而当前草稿需要复检或几何工具，可点击「用原图新建复检」。系统会复用同一原图创建独立的 **YOLO＋VLM 复检**任务，并保留当前草稿；原纯 YOLO 任务及其结果不变。等待新任务进入「已完成」或「部分完成」后再发送草稿；若新任务等待人工复核，先根据证据完成人工复核。该按钮只建立复检基线，不表示几何工具已经执行。

### 比较两个已保存的结果

同一会话中，确认上述两个任务均处于「已完成」或「部分完成」。展开「更换任务或对比结果」，选择当前任务和对比参考任务，不上传附件，再发送：

```text
比较这两个已保存的检查结果并生成对比报告，只使用已存证据，不重新运行模型。区分原始检测、复检和人工审核状态的差异，不把计数变化解释为实际缺陷的新增、消失或修复。
```

在回复下展开「保存结果对比」，核对两个任务 ID、类别计数、审核状态和报告。待复核任务暂不能比较；若其中一个仍待复核，先保留该状态，等有依据完成复核后再做对比，不为跑通示例而伪造决定。

## 如何判断测试结果

- 图片能上传、任务能恢复、模式和状态显示正确。
- 原始证据、增强图、检测分数、VLM 意见、人工决定可区分并追溯。
- 对不确定画面诚实保留不确定性；工具失败有明确状态，而非虚构成功结果。
- 报告与页面的任务 ID、发现项和复核状态一致。

每张图的观察重点是测试线索，**不是规定模型必须给出的答案**。原数据集的五类标注保存在 [sources.json](sources.json)；这是既有示例图的来源参考，可能与模型训练或以往实验重合，不能用这 6 张图推算准确率。06 的五类标注为空，但原数据属于非五类异常，**不是已验证的正常样本**。

图像均按源文件原样复制，没有加框、裁剪或增强；原有文字及 05 的蓝色遮挡块也保留。这次只准备了图片和说明，没有调用模型或替你提交人工复核。你实际发送对话和复检时会调用当前配置的服务；是否增强由明确授权后的选择结果决定。

结果可填写 [RESULTS.md](RESULTS.md)。这份小包只覆盖图片流程；视频时间线、视频选帧和真实正常图误报率不在本包范围内。
