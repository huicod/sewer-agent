## 01–06 现场图片的操作步骤

1. 若浏览器在自己电脑上运行，先把所选图片或 MP4 下载到本机，再通过网页选择。分轮指令可直接从对应目录复制。
2. 左侧点击「新建对话」，或切换到要继续的已有对话。中央「检查对话」是主要操作区；展开默认收起的「附件与检查选项」，上传对应的 `image.jpg` 并选择 **YOLO＋VLM 复检**。新图片通常从新对话开始；需要把多张图片明确放进同一对话时，也可在原对话里继续上传。
3. 复制该样本的首轮 prompt 到消息框并发送。回复“已启动”不等于检查已完成。右上点击「任务与证据」展开详情，查看任务状态、媒体证据和检查依据；消息中的「查看任务与证据」会直接定位到对应执行。
4. 核对原始框、复检意见和最终发现。若进入「等待人工复核」，按自己对证据的真实判断处理，不能照着目录名称一律确认；无法判断时可保留待复核。
5. 同一图片的追问和工具请求留在当前对话继续发送，无需新建对话或重复上传。每轮需要执行的请求会独立保存为任务，并列在该图片的执行记录下；可以连续多轮调用不同工具。需要明确改用另一项历史执行或比较两个结果时，展开「附件与检查选项」，手动选择目标任务和参考任务。

从工具子任务继续请求时，服务会追溯到原始图片执行；新的结果追加到历史，不覆盖原图、原始检查或先前工具证据。

## 复用图片的两个对照测试

### 同图两种模式

用 01 的同一张图片和同一条首轮 prompt，分别新建 **YOLO＋VLM 复检**、**纯 YOLO（不复检）** 两个任务，保存各自的任务 ID。模式必须在页面下拉框里切换；已有任务的模式不会被后续 prompt 改写。

观察两种结果是否正确显示自己的检查模式和证据来源。纯 YOLO 无框时应表述为“未检出五类缺陷（未复检）”，不能把它理解为人工审核后的正常结论。也不要求两种模式的缺陷数量必然不同。

若正在查看的是纯 YOLO 根图片任务，而当前草稿需要复检或几何工具，可点击「用原图新建复检」。系统会复用同一原图创建独立的 **YOLO＋VLM 复检**任务，并保留当前草稿；原纯 YOLO 任务及其结果不变。等待新任务进入「已完成」或「部分完成」后再发送草稿；若新任务等待人工复核，先根据证据完成人工复核。该按钮只建立复检基线，不表示几何工具已经执行。

### 比较两个已保存的结果

同一对话中，确认上述两个任务均处于「已完成」或「部分完成」。展开「附件与检查选项」，选择当前任务和对比参考任务，不上传附件，再发送：

```text
比较这两个已保存的检查结果并生成对比报告，只使用已存证据，不重新运行模型。区分原始检测、复检和人工审核状态的差异，不把计数变化解释为实际缺陷的新增、消失或修复。
```

在回复下展开「保存结果对比」，核对两个任务 ID、类别计数、审核状态和报告。待复核任务暂不能比较；若其中一个仍待复核，先保留该状态，等有依据完成复核后再做对比，不为跑通示例而伪造决定。

## 统一报告

点击右上「统一报告」，可下载当前对话的 HTML 或 JSON 报告。报告包含这个对话中的所有图片、各轮独立任务、父子关系、状态、覆盖情况、证据和工具结果。仍在运行的内容只是非最终快照；刷新报告后再核对最终状态。

报告按保存的图片来源和执行轮次组织。父任务与工具子任务中的发现不会跨轮合并去重，任务计数或类别计数也不能解释为现场物理缺陷总数、缺陷新增或修复。人工复核决定仍以实际证据为准。

## 如何判断测试结果

- 图片能上传、任务能恢复、模式和状态显示正确。
- 原始证据、增强图、检测分数、VLM 意见、人工决定可区分并追溯。
- 对不确定画面诚实保留不确定性；工具失败有明确状态，而非虚构成功结果。
- 单项和统一报告与页面的图片、任务 ID、父子关系、发现项和复核状态一致。

每张图的观察重点是测试线索，**不是规定模型必须给出的答案**。原数据集的五类标注保存在 [sources.json](sources.json)；这是既有示例图的来源参考，可能与模型训练或以往实验重合，不能用这 6 张图推算准确率。06 的五类标注为空，但原数据属于非五类异常，**不是已验证的正常样本**。

01–06 的图像按源文件原样复制；原有文字及 05 的蓝色遮挡块均保留。07–16 是带有模拟标记的公开教学素材。17 保留原始图像及数据参考框，18 是处理过的真实录像。新增示例的来源与变换见各目录中的 `source.json`。运行对话和复检时使用当前配置的服务，检测输出和审核意见请以实际任务为准。

结果可填写 [RESULTS.md](RESULTS.md)。这组示例适合测试操作流程；评估误报率或检出率需要另备独立的标注数据。
