# 07 · 从原始检测追问证据

上传 [模拟管道图片](image.jpg)，960 × 540。图中可以对照左壁的细线、环形接缝和底部反光。画面由 AI 原创生成，左上角有 `SYNTHETIC DEMO` 标记。它没有现场位置、工程尺寸或缺陷标注。

### ① 单图检测

点击「新建对话」→「新建检查」，上传图片，选择「纯 YOLO（不复检）」，把以下内容填入「检查要求」。点击「提交检查」，在「任务与证据」中点击「启动检查」。

```text
请用五类检测器检查这张模拟管道图，保留原始候选框和置信度，供我对照左壁细线、接缝和反光。
```

记录任务 ID 和实际框数。零个框也是可记录的结果。

### ② 追问同一份结果

检测完成后，在同一对话的「附件与检查选项」里选中刚才的任务，不再上传文件，发送以下内容。

```text
解释这个任务已保存的结果。哪些位置有原始检测框？如果没有框，请说明当前检测范围和复检状态。只引用已经保存的证据。
```

对照任务 ID、框的位置和「未复检」标记。此步可验证聊天是否引用了正确的任务。

### ③ 用同一原图做复检

需要检测与复检对照时，点击「用原图新建复检」，记录独立的任务 ID。等新任务完成或部分完成，或按证据实际处理人工复核。在「统一报告」里查看两轮各自的状态和证据。对比时可选择两项已完成或部分完成的任务。此示例不预设复检会增加或删除候选。
