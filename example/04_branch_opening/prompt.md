# 04 · 接入口与边缘

图片：[image.jpg](image.jpg)，720 × 576。洞口、接管边缘和局部壁面纹理明显；源数据集有 AJ（支管暗接）标注，是否构成该缺陷仍需结合可见证据判断。

## 首轮

上传本目录图片，选择「YOLO＋VLM 复检」，不要在「更换任务或对比结果」中另选已有任务，然后发送：

```text
请检查这张管道图片中的五类缺陷，结合洞口、接管边缘和周围管壁的原始证据进行复核。不要仅因存在圆形开口就确认异常；证据不足的内容保留待人工判断。
```

重点看：接入口候选的定位、边缘可见性和复检依据；“支管开口”与“已确认不合规或破损”是否被混为一谈。

## 选做：报告与刷新恢复

在任务完成或部分完成后，可点击详情中的「HTML 报告」「JSON 报告」。也可在中间查看该任务并清除附件后发送；若草稿已锁定到先前目标，先点击「讨论当前查看的任务」：

```text
根据这个任务已经保存的检查证据生成报告，保留缺陷位置、原始证据和人工复核状态，不重新运行检查。
```

若仍待人工复核，先检查证据，完成有依据的决定后再取最终报告。核对报告任务 ID 和发现项是否与页面一致，再刷新网页检查会话与任务是否恢复。
