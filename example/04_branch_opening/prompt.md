# 04 · 接入口与边缘

图片：[image.jpg](image.jpg)，720 × 576。洞口、接管边缘和局部壁面纹理明显；源数据集有 AJ（支管暗接）标注，是否构成该缺陷仍需结合可见证据判断。

## 首轮

左侧新建或切换到本图的对话，在中央「检查对话」展开「附件与检查选项」，上传本目录图片并选择「YOLO＋VLM 复检」，然后发送：

```text
请检查这张管道图片中的五类缺陷，结合洞口、接管边缘和周围管壁的原始证据进行复核。不要仅因存在圆形开口就确认异常；证据不足的内容保留待人工判断。
```

重点看：接入口候选的定位、边缘可见性和复检依据；“支管开口”与“已确认不合规或破损”是否被混为一谈。

右上点击「任务与证据」可展开详情；消息中的「查看任务与证据」会直接定位到本轮执行。

## 选做：报告与刷新恢复

在任务完成或部分完成后，可点击右上「统一报告」下载当前对话的 HTML 或 JSON 报告，其中包含本对话所有图片和执行轮次。也可留在同一对话直接发送下面的追问，无需重传图片；需要指定历史执行时，展开「附件与检查选项」选择目标：

```text
根据这个任务已经保存的检查证据生成报告，保留缺陷位置、原始证据和人工复核状态，不重新运行检查。
```

若仍待人工复核，先在「任务与证据」中检查证据，完成有依据的决定后再取最终报告。核对报告中的图片、任务 ID、父子关系和发现项是否与页面一致，再刷新网页检查对话与任务是否恢复。运行中报告只是非最终快照；父子任务的发现不会跨轮累计，不能把计数当作物理缺陷总数。
