# 18 · 连续现场录像中的事件与证据帧

上传 [10.4 秒现场片段](clip.mp4)。它来自真实巡检录像，保留连续画面，遮去顶部现场文字、移除音频并缩小分辨率；来源与处理方式见 [source.json](source.json)。

> 检查这段视频，按时间列出模型标记的候选事件。给出每个事件的时间范围和证据帧，注明哪些帧画质不足、哪些结论仍要人工判断。

打开“视频候选时间线”核对总帧数、完整解码状态和证据时间。若有已存帧，选一帧并明确请求“对选中的证据帧做低照度增强”，保留父任务 ID 和原始时间戳。本次纯本地初查保存的帧数和候选时间见[初查记录](../RESULTS.md)。

原录像曾做过历史实验。这里经过遮挡、缩小和重新编码，检测框、时间及分数以当前片段运行结果为准。
