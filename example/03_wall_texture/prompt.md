# 03 · 低对比度侧壁纹理

图片：[image.jpg](image.jpg)，1920 × 1080。侧壁纹理、接缝、反光及水面并存；源数据集在右侧窄区域有 FS（腐蚀）标注，需留意标注与可见证据是否一致。

## 首轮

左侧新建或切换到本图的对话，在中央「检查对话」展开「附件与检查选项」，上传本目录图片并选择「YOLO＋VLM 复检」，然后发送：

```text
请检查这张管道图片中的五类缺陷，并复核低对比度区域。区分管壁纹理、污渍、潮湿反光与有证据的缺陷；无法从原图确认的内容保留不确定性。本轮不做图像增强。
```

重点看：窄小侧壁区域是否漏检；文字、接缝或亮线是否被误认；复检建议改类时是否仍保留原始检测类别和分数，避免把旧分数当作新类别的置信度。

右上点击「任务与证据」，再展开「检查依据」，逐项对照图中位置；消息中的「查看任务与证据」可直接定位。若进入人工复核，应写自己的观察理由，不预填固定答案。
