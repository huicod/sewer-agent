# 01 · 细线纹理

图片：[image.jpg](image.jpg)，640 × 640。可见纵向细线与明暗变化；源数据集有 PL（破裂）标注，实际判断仍以图像证据为准。

## 首轮

左侧新建或切换到本图的对话，在中央「检查对话」展开「附件与检查选项」，上传本目录图片并选择「YOLO＋VLM 复检」，然后发送：

```text
请检查这张管道图片中的五类缺陷，结合原图证据进行复核；证据不足的发现保留不确定性，供人工审核。本轮不做图像增强或几何测量。
```

重点看：细线位置是否准确；是否把光照边缘或普通纹理当作缺陷；原始检测与复检意见能否分别查看。可用同一条 prompt 和同一张图片另建「纯 YOLO（不复检）」任务，做模式对照。

右上点击「任务与证据」可展开详情；消息中的「查看任务与证据」会直接定位到本轮执行。

## 选做：指定区域分割与相对量化

等原始的「YOLO＋VLM 复检」任务已完成或部分完成后，留在同一对话直接发送，无需重传图片。若要从别的执行切回本任务，展开「附件与检查选项」手动选择目标；也可在消息中点击「查看任务与证据」定位后核对：

```text
对关联原图的像素框 [245, 104, 348, 436] 做分割和相对量化，并生成报告。对该区域生成分割掩膜，结合整图相对深度统计该区域的像素和相对量，不推算毫米尺寸、实际深度或管道堵塞率。
```

这里是 640 × 640 **原图像素坐标**，不是归一化坐标。ROI 来自该图已有实验中的原始检测框取整，只用作工具提示，不是掩膜真值。分割和相对量化会调用分割与相对深度工具；不要在同一条请求里再加入增强。

重点看：生成关联任务、几何证据和像素/相对量；掩膜可能跟随背景而非细线，应人工查看，不能把“工具成功”当作“分割正确”。

还可在后续消息继续请求其他工具；每轮执行独立保存并列在同图执行记录下。从这个工具子任务继续请求时，服务仍会回到原图，历史掩膜、深度和检查证据不会被覆盖。

若当前只有同图的「纯 YOLO（不复检）」根图片任务，可先输入上面的几何草稿，再点击「用原图新建复检」。这会复用原图创建独立的 YOLO＋VLM 任务并保留草稿，不会改写纯 YOLO 历史任务。等待新任务「已完成」或「部分完成」后再发送；若进入待人工复核，先按图像证据处理人工复核。新任务完成基线不代表 ROI 分割或相对量化已经成功，仍需发送草稿并人工核对结果。
